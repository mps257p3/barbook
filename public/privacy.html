Política de Privacidade

On the Rocks · Atualizado em abril de 2026

Esta Política de Privacidade descreve como o aplicativo On the Rocks coleta, usa e armazena informações dos usuários. Ao usar o app, você concorda com as práticas descritas aqui.

1. Responsável pelos dados

Marcelo Parducci dos Santos
marceloparducci@gmail.com

2. Dados coletados

O app pode coletar e armazenar as seguintes informações:

  • Dados de conta Google — nome, e-mail e foto de perfil, quando o usuário opta por fazer login com o Google.
  • Dados gerados pelo usuário — receitas personalizadas criadas dentro do app, lista de ingredientes marcados como disponíveis ("Meu Bar"), drinks marcados como favoritos ou como já provados, e avaliações.
  • Dados de uso local — preferências e configurações armazenadas no dispositivo via localStorage.

3. Como os dados são usados

  • Sincronizar suas preferências e receitas entre dispositivos quando você está conectado.
  • Exibir seus dados dentro do próprio app (favoritos, bar, receitas criadas).
  • Melhorar o conteúdo do app — receitas frequentemente adicionadas pelos usuários podem, no futuro, ser incorporadas ao acervo oficial, sempre de forma anônima.

Seus dados não são vendidos a terceiros nem usados para fins publicitários.

4. Armazenamento

Os dados dos usuários autenticados são armazenados no Firebase (Google LLC), plataforma segura com criptografia em trânsito e em repouso. Dados de usuários não autenticados ficam apenas no dispositivo.

5. Compartilhamento de dados

Os dados não são compartilhados com terceiros, exceto pelos serviços de infraestrutura necessários para o funcionamento do app:

  • Firebase / Google — autenticação e banco de dados
  • Vercel — hospedagem do aplicativo

6. Retenção e exclusão

Você pode excluir seus dados a qualquer momento entrando em contato pelo e-mail abaixo. Dados de usuários que não acessam o app por mais de 2 anos poderão ser removidos automaticamente.

7. Menores de idade

O On the Rocks é um aplicativo destinado exclusivamente a maiores de 18 anos. Não coletamos intencionalmente dados de menores de idade.

8. Alterações nesta política

Eventuais atualizações serão publicadas nesta página com a data de revisão atualizada. Recomendamos que você a consulte periodicamente.

9. Contato

Dúvidas, solicitações de exclusão de dados ou qualquer outra questão relacionada à privacidade:
